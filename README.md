# foundry-modules

Foundry VTT modules by karpiq24. The sources live in a private repository; this repository
only holds the released modules (see Releases). Install a module in Foundry from its manifest
URL (*Add-on Modules → Install Module → Manifest URL*):

| Module | Manifest URL |
|---|---|
| `rpgnotes-recorder`: records a session's chat, rolls, scenes and map snapshots for the session-notes pipeline | `https://github.com/karpiq24/foundry-modules/releases/download/rpgnotes-recorder-latest/module.json` |
| `rpgassistant-live`: sends the game's chat, rolls and scenes to a local live DM assistant (GM only) | `https://github.com/karpiq24/foundry-modules/releases/download/rpgassistant-live-latest/module.json` |
